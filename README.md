# Soft Skies

Soft Skies is a relaxing low-poly flight sim about drifting through bright open skies, gentle terrain, and quiet procedural landscapes.

Take flight as a colorful phoenix and explore an open, ever-unfolding world of plains, mountains, rivers, clouds, and shifting daylight. There are no scores, timers, or combat - just smooth free-flight, soft scenery, and a calm place to wander.
